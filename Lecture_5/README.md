# Connect Hub

Домашнее задание к лекции 5: «Async React: Effects & API».

Каталог пользователей на React. Данные приходят из фейкового API (`src/api/fakeApi.js`), который отвечает с задержкой и иногда возвращает ошибку.

## Страницы

- `/` — список пользователей: поиск, фильтры, сортировка, кнопка «Load more», детали пользователя
- `/users/:id` — профиль пользователя
- `/users/new` — создание пользователя
- `/users/:id/edit` — редактирование пользователя

## Что умеет

- Состояния загрузки, ошибки и пустого списка, кнопка Retry
- Создание, редактирование и удаление пользователей
- Адаптивная вёрстка для телефона и компьютера

## Запуск

```bash
npm install
npm run dev
```

## Стек

React, React Router, Tailwind CSS, Vite
